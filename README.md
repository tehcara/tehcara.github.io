# Portfolio Website (Front-End Architecture)
A professional, accessible, and performance‑focused portfolio built with semantic HTML5 and custom CSS3.

## Project Overview
Originally launched in 2024 and continuously refined, this portfolio demonstrates my approach to front‑end development: clean structure, accessibility‑first design, and thoughtful performance optimisation. It also hosts project documentation, GUI showcases, and technical evidence for my CV.

Live Site: https://tehcara.github.io/

## Technical Highlights
* **Accessibility**: Developed with end users in mind, featuring keyboard navigation shortcuts, ARIA labels, and high‑contrast styling to meet WCAG standards.
* **Quality Assurance**: Validated with W3C standards to ensure cross‑browser compatibility and promote easy maintenance.
* **Performance**: Optimised image assets, preconnect and efficient loading for Google Fonts, a custom favicon set, and a dependency‑free architecture.
* **Environment Integrity**: Managed via a Git workflow with feature branches to ensure the live production site remains stable during updates. Incremental improvements are tracked through commits.
